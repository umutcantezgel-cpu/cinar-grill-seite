# cinar-grill-seite
Produktionsreifes Restaurant-Projekt für Cinar Grill, inspiriert von der Struktur &amp; UX-Heuristik von palaiswetzlar.de/restaurant (ohne Content-Übernahme). Enthält Design-Tokens, Consent-Flow &amp; 2-Klick-Map, Security-Header (CSP/HSTS/SRI), SEO &amp; strukturierte Daten (Restaurant), Lighthouse/Pa11y-Audits, GitHub-Actions-CI und Netlify-Konfiguration.
